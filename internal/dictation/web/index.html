识别引擎

模型名，或本地模型目录的绝对路径。必须与后端匹配。

麦克风

试录用的是上面选中的设备（不用先保存），但识别用的是当前正在运行的模型。说话时电平应在 −40 dB 以上；只有 −60 dB 左右，说明录到的只是底噪。

热词

每行一个词，# 开头是注释。保存后下次转写立即生效，不用重启。热词的偏置作用很强，写错的词会把本来认对的结果带偏，宁缺毋滥。

替换规则

识别出来后再按规则改字，专治模型老是认错的同音字。每行一条 原文 => 替换，# 开头是注释，保存后下次转写生效。长的规则优先：写 他 => 它 再写 其他 => 其他，「其他」就会原样保留，其余的「他」都变成「它」。
